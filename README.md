# 🍔 Burger Quest

> "세상의 모든 햄버거를 먹어봤지만 만족할 수 없었다. 그렇다면 직접 최고의 햄버거를 만들자."

몬스터를 처치해 재료를 모으고, 레시피를 완성하며 최고의 햄버거를 만들어가는 C++ 콘솔 RPG입니다.

## 프로젝트 소개

Burger Quest는 C++ 객체지향 설계를 기반으로 개발한 콘솔 RPG입니다. 플레이어는 전투를 통해 다양한 식재료를 획득하고, 레시피를 해금하여 요리를 완성하면서 능력치를 성장시킵니다. 모든 레시피를 완성하면 최종 보스와의 전투가 진행되며, 최고의 햄버거를 완성하는 것이 목표입니다.

## 개발 목표

이번 프로젝트는 단순히 게임을 구현하는 것보다 **객체지향 설계와 팀 협업 경험을 쌓는 것**을 가장 중요한 목표로 두었습니다.

특히 클래스 간 의존성을 최소화하는 구조를 설계하여 각 기능을 독립적으로 개발할 수 있도록 하였으며, 명확한 인터페이스를 기반으로 협업을 진행했습니다. 이를 통해 기능 구현뿐만 아니라 코드 리뷰, Pull Request, 인터페이스 설계, 역할 분담, 팀원 간 소통 등 실제 협업 과정에서 필요한 경험을 쌓는 데 중점을 두었습니다.

## 주요 기능

* 몬스터와의 턴제 전투
* 레벨 및 능력치 성장
* 재료 획득 및 인벤토리 관리
* 레시피 해금 및 요리 시스템
* 요리 완료 시 영구 능력치 증가
* 최종 보스 전투
* ASCII Art 기반 UI
* 전투 로그 및 게임 진행 로그

## 프로젝트 구조

* **GameManager** : 게임 전체 흐름 관리
* **BattleManager** : 전투 로직 관리
* **CookingManager** : 요리 및 레시피 관리
* **RecipeManager** : 레시피 데이터 관리
* **UIManager** : 화면 출력 및 사용자 입력 처리
* **LogManager** : 게임 로그 관리
* **Character / Player / Monster** : 캐릭터 계층 구조
* **Inventory** : 아이템 및 재료 관리

## 설계 원칙

* Single Responsibility Principle(SRP)를 고려한 클래스 분리
* 클래스 간 결합도 최소화
* 인터페이스 중심의 협업
* 출력(UI)과 게임 로직의 분리
* Manager 클래스를 통한 기능별 책임 분리

## 개발 환경

* C++17
